## 1. 这轮实验回答了什么

**两条增加局部漏检的作用路径得到了支持，但还不能据此把全部 empty 问题归因于 CE、Lovász 和 Set 分类损失。针对其中一条路径设计的幅度投影，也没有超过同等类别 bias 校准后的基线。**

| 关注的问题 | 本轮结论 |
| --- | --- |
| Set 分类为什么可能增加漏检？ | 压低非目标前景通道时，会削弱 Gaussian 的前景贡献；目标通道的监督则有相反作用 |

## 2. 哪些监督增加漏检，哪些监督在纠正漏检

### 先把损失名称和指标说清楚

“前景”指 17 个 occupied 类别，包括道路；empty 为第 18 类。下列名称均按监督来源划分：

- **Set 正类／负类：** Gaussian 匹配目标对应的一个前景通道／其余 16 个前景通道。Set 负类不包含 empty。
- **CE 前景／CE empty：** 真实前景体素／真实 empty 体素对 CE 的贡献。这里按真值划分，不是按预测结果或输出通道划分。
- **Lovász：** 当前配置会忽略真实 empty 体素，但仍通过前景体素的 18 类 softmax 参与类别竞争。

除明确写“全部阶段”外，Set 干预均只针对最后阶段分类项；所有实验均保留 Set loss 的几何监督。

**漏检率**是“被判 empty 的真实前景占全部真实前景的比例”；**误占用率**是“被判前景的真实 empty 占全部真实 empty 的比例”。二者越低越好。**mIoU**是 17 个前景类别 IoU 的平均，越高越好。

以下表格中的变化量统一用**百分点**。例如，漏检率变化为 +0.0650，表示漏检率升高 0.0650 个百分点，而不是升高 6.5%。

{{ value:source_table }}

这张表最值得关注的是三点。

**第一，Set 负类和 CE empty 都增加了局部漏检。** 但二者同时减少误占用，且各自的 mIoU 都略有提高。因此，“增加漏检”不能直接等同于“这项监督整体有害”。

**第二，完整 CE 仍然减少漏检。** 真实前景上的 CE 有更强的纠正作用，两部分按原权重相加后，净结果仍为减少漏检。Lovász 和完整联合更新也呈现这一方向。

**第三，empty 分数并没有变化，漏检仍然可以增加。** 前景分数被压低后，原本接近决策边界的体素就可能转为 empty。这支持“前景证据减弱”的解释，不能简单写成“empty logit 被学得过高”。

Set 负类和 CE empty 的漏检增加，在 epoch 1、3、5 三个 checkpoint 中方向一致，场景区间均高于零。完整数值见附录 A。这里的稳定性来自同一训练过程的多个阶段与多个场景，尚不是跨训练 seed 或跨模型的普遍结论。

## 3. 为什么空体素上的 CE 会影响真实前景

关键在于：**同一个 Gaussian 会参与多个体素的预测，其中可能既有真实 empty，也有真实前景。**

> 空体素被误判为前景 → CE 要求降低该处前景分数 → 梯度传到提供这些分数的 Gaussian → 同一个 Gaussian 在真实前景位置提供的分数也可能下降。

这条解释有两类互补证据。

**空间统计说明这条路径有机会发生。** 在 epoch 1、3、5 的验证诊断样本中，分别有 {{ value:mixed_text }} 的有效 Gaussian 同时向真实前景和真实 empty 提供空间贡献。比较目标类别、幅度、尺度和空间支持相近的 Gaussian 时，empty 覆盖比例较高的一组，受到的 CE empty 幅度抑制也更强。

**固定其他因素的干预说明它确实能产生前景代价。** 第 2 节只沿 CE empty 来源更新分类输出，空间权重和 empty 分数保持不变，真实前景漏检仍然增加。

空间相关性本身不能估计这条路径对全部错误的贡献。高覆盖组也可能包含只覆盖 empty 的 Gaussian；其幅度下降未必伤及前景。因此，本轮把空间统计与干预结果结合解释，没有用覆盖比例直接推算前景损失。

我们还检查了 Set 分类与 CE empty 同时出现时，是否存在超出各自作用的额外放大。{{ value:interaction_text }}这意味着目前缺少稳定协同放大的证据，不代表已经证明二者完全独立。

## 4. 针对这条路径设计的方法，有没有额外收益

### 幅度投影做了什么

每个 Gaussian 的“语义总幅度”，是其 17 个 softplus 语义值之和。**幅度投影**从 Set 分类梯度中去掉直接改变这个总和的分量，保留其余方向。它只修改最后阶段 Set 分类的反向传播，CE、Lovász 和前向计算保持原方式。

这个操作约束的是当前输出空间中的一阶变化。真实训练还涉及共享参数、其他损失和 AdamW 历史动量，所以训练后的幅度仍然可以改变。精确定义见[实验设计](empty_mechanism_stage2_design.md)。

### 64 步续训有原生收益，但还不足以说明方法成功

从 epoch 1、3 出发，分别比较原训练目标、删除监督、分类减半、幅度投影和匹配梯度长度等条件。每个条件用同样的数据和增强继续训练 64 步，再评价固定 32 个验证场景。

在这套评价中，{{ value:short_summary_text }}。但从 epoch 3 出发时，投影相对原目标、分类减半及匹配梯度长度的配对区间都包含零，优势还不稳定。完整消融表见附录 C。

另一个值得关注的信号是：早期投影模型的 mIoU 提高了，但暂时忽略 empty、只在 17 个前景类别之间选最高分时，类别正确率反而有所下降。也就是说，**原生 mIoU 提高，不等于前景类别区分能力也提高了**。这促使我们追加同等类别校准对照。

### 两个模型都校准后，投影的优势没有保持

这里的**原生**指直接使用模型训练后的决策方式，其中已经包含原有的可学习全局 empty bias。**类别校准**则额外为每个首选前景类别拟合一个固定的 empty 决策阈值：保留前景类别排序，只改变它胜过 empty 的难易程度。

对原训练模型和投影模型，分别使用相同的完整 4096 个训练帧拟合、调参；参数固定后，在完整 1024 个验证帧上评价。验证标签不参与阈值选择。这是训练后拟合的强静态参照，没有重新训练此前的可学习类别 bias 模块。

## 5. 本轮之后，机制结论应该怎样表述

当前较准确的表述是：

> 在本轮 OPUS Semantic Gaussian 配置中，Gaussian 的语义值同时承担类别区分和前景渲染强度两种作用。Set 分类对非目标前景通道的压制，以及真实 empty 体素的 CE 监督，都可以通过这些共享语义值削弱部分前景证据。完整监督的净作用、空间共享和优化器历史，共同决定最终预测。

这一结论支持继续研究“类别区分与占有证据强度如何耦合”，但还没有解释全部残余漏检，也没有证明所有 Semantic Gaussian 方法拥有相同训练根因。

对下一步方法设计，本轮给出三个约束：保留前景类别区分能力；保留对真实空体素的有效抑制；在同等类别 bias 校准后仍检验是否有额外收益。仅靠提高总幅度、减少漏检或改善未校准 mIoU，证据都不充分。

跨表征的结论也需另做比较。当前 [OPUS 点离散化代码](../../../model/head/opus_rasterizer.py)同样使用分类置信度阈值，本轮不能推导出“只有 Gaussian 才会出现这种敏感性”。

### C2. Gaussian 幅度与 empty 参数怎样变化

{{ value:parameter_table }}

“Gaussian 平均总幅度”先对每个 Gaussian 的 17 个非负语义值求和，再对 Gaussian 和帧取平均；它不是体素的空间加权分数。全局 empty bias 越大，最终 empty 分数越低；empty scalar 越大，原始 empty 强度越高。
