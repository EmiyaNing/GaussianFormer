# A3｜预测器更准，是因为信息更好，还是因为点覆盖不同？

[返回总览](README.md) · [上一篇：A2 距离](a2_migration.md) · [下一篇：A4 输入干预](a4_input_interventions.md)

> **先看结论：**原来的静态局部优势对 query 数量、空间分布和空间填补很敏感。比较 F 与 P 时，需要把“输入信息”与“信息如何形成三维输出”一起考虑。
>
> 范围：150 样本／150 场景；这里的局部区域始终指“只进入未来窗口视锥的静态 GT 体素”。

## 先看输出是怎样形成的

SparseWorld 用一组 **query（可学习的三维表示单元）**生成三维点，每个 query 最终输出 48 个点。点带有位置和类别分数，经过过滤、落入体素网格，再经过空间后处理，才变成准确率图中的结果。

![从 query 到最终体素标签的处理流程](figures/guide_a3_pipeline.png)

**原版 3 秒输出中，F 有 1040 个 query，P 有 720 个。**它们的点预算本来就不同。此外，代码中的 `padding` 在这里指网格上的闭运算及原有体素保留，它可以填补部分空间空隙，并非给输入图像补边。

## 如何把几个因素拆开比较？

| 对照 | 实际改变什么 | 想回答的问题 |
|---|---|---|
| 等 query 数 | F 随机保留 720 个完整 query，P 保持 720 个 | 相同数量下，原来的优势还在吗？ |
| 等空间配额 | 每个 4 m 水平块内，双方保留相同数量的 query 中心 | 空间分配更接近时，差值如何变化？ |
| 关闭空间填补 | F、P 都关闭 padding | 最终优势有多依赖网格后处理？ |
| 其他过滤／阈值对照 | 双方一起关闭组过滤，或一起改分数阈值 | 结果是否只是某个筛选阈值造成的？ |

等空间配额后，3 秒时每支平均保留 551.47 个 query。删点会同时改变数量、位置和 query 身份，因此这些是诊断干预，不能据此算出“点数独自解释了百分之多少”。

## 换一个随机种子，结论还成立吗？

初筛后，我们追加了三个采样种子，测试 360／540／720 个 query，以及开启／关闭空间填补的组合。

{{A3_SEED_SHORT}}

在 720 query、保留原版空间填补时，三个种子的点估计都偏向 P，但后两个区间仍跨 0。更低预算时，方向还会随采样变化。因此，最稳妥的结论是：**F 原有优势对点预算与空间覆盖敏感；还不能宣布等预算后 P 在所有采样下都显著更强。**全部组合见[统计附表](statistics.md#a3)。

## 还有两个值得保留的线索

**改变 P 的初始覆盖范围，可以改善局部，却损害整体。**取消自适应缩放后，这个静态子集准确率提高 3.77 个百分点，区间 `[2.42, 5.21]`；整体 3 秒 mIoU 却从 17.71% 降至 16.44%。

**位置与语义也有不同贡献。**保持 F 的点位置，用 1.2 m 内 P 最近点的语义分数替换后，F 的 3 秒 mIoU 从 11.43% 升到 13.16%。反向保留 P 的位置、换入 F 的语义，P 则从 17.71% 降到 13.68%。两方向平均匹配率约为 96.05%／96.35%。

最近点交换允许多对一，并且使用了真实未来输入。这是拆分几何与语义作用的诊断，尚不是可以部署的预测改进。

## 对下一步方法设计的启发

应先在固定点预算、统一后处理的条件下，研究怎样分配和保留空间覆盖，再判断哪些教师语义值得学习。只根据原始准确率图选择“更可信的一方”，可能把表示方式的差异也一起学进去。
