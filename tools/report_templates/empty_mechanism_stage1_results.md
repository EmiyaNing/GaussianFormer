# Empty 机制实验结果：语义幅度如何影响空类别漏检

实验日期：2026-10-18。状态：**实验完成，完整性审计通过。** 本次修订重组解释与符号定义，实测数据沿用原实验记录。

相关文档：[研究规则与完整符号表](../plans/semantic_gaussian_empty_mechanism_rules.md) · [实验设计与操作步骤](empty_mechanism_stage1_design.md) · [全部主实验条件](empty_mechanism_stage1/all_interventions.csv)

## 1. 先说这份报告能回答什么

**本轮发现了一条局部作用路径：set 分类更新在改善类别区分的同时，可能压低 Gaussian 的语义总幅度；幅度下降又会使部分真实前景更容易输给 empty。**

证据来自同一模型训练轨迹的 epoch 1、3、5。直接修改语义输出、更新真实分类参数、在另一个场景评价，均观察到了这条路径。但完整分类更新仍可能提高 mIoU，联合体素目标也能减少漏检，因而不能据此认定 set loss 整体有害。

模型已在 4096 帧 mini set 上训练。本轮复用这些权重进行局部干预，并用 epoch 5 完成 1024 个验证帧的基线统计；全部体素评价和场损失均采用默认 camera mask。**这些干预结果不是重新训练一个新模型后的性能。**

建议先读第 2 节理解“幅度”和“组成”，再读第 4–6 节的干预证据。样本数量、区间和数值检查放在文末附录，便于核查。

## 2. 看懂实验，只需区分两个层次

### 2.1 Gaussian 层：一个语义值可以拆成“总量 × 份额”

用 $i$ 表示 Gaussian 编号，$G$ 表示前景 Gaussian 总数；用 $c$ 表示前景类别编号，类别集合为 $\mathcal C=\{0,\ldots,16\}$。这些前景类别包括道路等静态类别。额外的 empty Gaussian 不计入 $G$。

| 符号 | 属于哪个对象？ | 具体含义 |
| --- | --- | --- |
| $u_{i,c}$ | Gaussian $i$ 的类别 $c$ | 原始分类 logit，可正可负，set 分类损失使用它 |
| $s_{i,c}$ | Gaussian $i$ 的类别 $c$ | 经 softplus 得到的非负语义值，渲染器使用它 |
| $a_i$ | 一个 Gaussian | 17 个语义值的总和，称为**语义总幅度** |
| $p_{i,c}$ | 一个 Gaussian 内的一个类别 | 该类占总幅度的份额，称为**类别组成** |

$$
s_{i,c}=\operatorname{softplus}(u_{i,c})
       =\log(1+\exp(u_{i,c})),
\qquad
a_i=\sum_{c\in\mathcal C}s_{i,c},
\qquad
p_{i,c}=\frac{s_{i,c}}{a_i}.
$$

这里要求 $a_i>0$；有限 logit 的 softplus 输出在数学上满足这一条件。因此 $s_{i,c}=a_ip_{i,c}$。**幅度衡量语义值的总量，组成衡量总量分配给了哪些类。** 份额加和为 1，但不自动等于真实类别概率；它是从现有输出计算的诊断量，不是新增的概率头。

### 2.2 体素层：前景分数还要与 empty 竞争

用 $x$ 表示一个体素中心的三维位置。以下量都在该体素处计算：

| 符号 | 定义 |
| --- | --- |
| $w_i(x)$ | Gaussian $i$ 对体素的非负空间权重，受位置、尺度、旋转和 opacity 影响 |
| $z_c(x)$ | 所有前景 Gaussian 对类别 $c$ 的贡献之和 |
| $E(x)$ | 已减去 checkpoint 原全局 bias 的 empty 分数 |
| $m(x)$ | 最高前景分数减去 empty 分数，旧文称 margin |

$$
z_c(x)=\sum_{i=1}^{G}w_i(x)a_ip_{i,c},
\qquad
m(x)=\max_{c\in\mathcal C}z_c(x)-E(x).
$$

当 $m(x)<0$ 时，empty 获胜。**前景类别之间的排序正确，不保证最高前景分数足够高。** 一个示意例子如下：只有一个贡献权重为 1 的 Gaussian，empty 分数固定为 5。数字仅用于解释概念。

| 条件 | 总幅度 × 正确类份额 | 正确前景分数 | 与 empty 比较后的结果 |
| --- | --- | --- | --- |
| 更新前 | $10\times0.60$ | 6.00 | 正确前景 |
| 更新后 | $8\times0.62$ | 4.96 | empty |

正确类的份额提高了，但总幅度下降更多，最终仍可能转为空。

本报告把“真实为前景、前景首选正确、最终却为空”的体素称为**可恢复漏检**。“可恢复”表示已有正确前景首选，不保证一个实际方法能无代价地救回它。

原模型已带全局 learnable empty bias，epoch 5 的该值为 3.5585。本轮固定该 bias 以及 empty 分支，研究的是现有模型剩余误差的路径。

### 2.3 结果表中的增量怎么读？

- **漏检率：** 预测为空的真实前景数，除以全部真实前景数。
- **误占用率：** 预测为任意前景的真实 empty 数，除以全部真实 empty 数。
- **mIoU：** 17 个前景类别 IoU 的算术平均；每类 IoU 是正确交集数除以预测与真值的并集数。
- **场损失：** 原体素交叉熵与 Lovász 的加权和，乘数分别为 10 和 1。

$\Delta$ 统一表示“干预后减去原状态”。率和 IoU 的增量单位为**百分点**：41.20% 变成 41.25% 是 +0.05 个百分点。损失增量使用损失本身的数值单位。

率和 IoU 由该组样本汇总后的混淆矩阵计算；场损失按帧取平均。表中的区间描述场景之间的统计不确定性，具体计算方式见附录 A。

## 4. 如果把幅度恢复，漏检会怎样变化？

### 4.1 先说清“恢复幅度”到底做了什么

沿选定损失更新一次后，用 $a'_i$、$p'_{i,c}$ 表示新幅度与新组成。撇号只表示“更新后的值”，不是求导。随后把新旧两组量交叉组合：

| 条件 | 渲染使用的语义值 | 用普通语言解释 |
| --- | --- | --- |
| 原状态 | $a_ip_{i,c}$ | 没有施加本次更新 |
| 仅幅度更新 | $a'_ip_{i,c}$ | 保留原份额，只换总幅度 |
| 仅组成更新 | $a_ip'_{i,c}$ | 保留新份额，把总幅度恢复为原值 |
| 完整语义更新 | $a'_ip'_{i,c}$ | 使用这次更新的全部语义变化 |

几何、opacity 和 empty 分支固定，所有条件都与同一个原状态比较。“仅幅度更新”固定每个 Gaussian 的组成；不同 Gaussian 的相对贡献仍可能变化，所以不能保证聚合后的体素前景排序固定。

### 4.2 直接更新语义输出：幅度路径复现了漏检增量

下面直接对 Gaussian 原始 logits 做一次 Set 分类负梯度更新，网络参数固定。Set 分类指原损失最后阶段的 sigmoid focal 分类部分，保留原权重，不包含 set 几何项。

## 5. 幅度为何下降？正类增量小于其余类别的合计降幅

这项分析是在主实验观察到幅度路径后追加的，属于探索性归因，仍使用原场景和步长。

### 5.1 “正类”“负类”与数值正负无关

对 Gaussian $i$，用 $t_i\in\mathcal C$ 表示原 set loss 匹配到的目标类别：

- **正类通道：** 目标类别 $t_i$ 对应的一个通道。
- **负类通道：** 其余 16 个前景类别的通道，**不包括 empty**。
- 所有 $s_{i,c}$ 都是非负语义值；“负类”不表示语义值为负。

$t_i$ 是点级匹配目标，不是体素真实标签。令 $\Delta s_{i,c}=s'_{i,c}-s_{i,c}$ 表示一个通道的实际变化，$\Delta a_i=a'_i-a_i$ 表示总幅度变化，则：

$$
\Delta a_i
=
\Delta s_{i,t_i}
+
\sum_{\substack{c\in\mathcal C\\c\ne t_i}}\Delta s_{i,c}.
$$

等号右侧依次是目标类变化与其余 16 类的合计变化。该式是精确的加和关系，不依赖小步长近似；梯度形式及其符号解释放在[研究规则第 6 节](../plans/semantic_gaussian_empty_mechanism_rules.md)。

## 6. 为什么不能因此认定 Set 分类整体有害？

### 6.1 同一次更新，漏检增加但 mIoU 仍提高

下面使用 **epoch 5、32 个验证场景、完整输出更新、相对步长 0.001**。交叉熵与 Lovász 保留原训练乘数，联合目标为 Set 分类加场损失。

{{ table:tradeoff }}

前三个指标的增量单位为百分点；场损失增量是损失值之差。Set 分类方向使漏检增加，但减少误占用并改善前景类别区分，mIoU 最终仍上升。

“减少 empty 漏检”和“提高语义 mIoU”不是完全相同的目标。仅组成更新的 mIoU 增量为 +0.3394，完整更新为 +0.3533；恢复幅度在这个输出实验中并未取得更高 mIoU。

### 6.2 净增漏检，不等于原来语义正确的体素都丢失了

epoch 5 完整输出更新净增 **324** 个 empty 漏检，但其中并非全是原来语义正确的前景。该更新同时救回 **136** 个原可恢复漏检，并使 **34** 个原先语义正确的前景转为空。其他变化还包含原先类别预测错误、二值上却预测为 occupied 的体素。

幅度路径确实会损害一部分原正确预测；不过不同路径也会改变误占用和类别混淆，最终方法仍需完整评价。

### 6.3 联合目标能够抵消局部副作用

三个 checkpoint 的完整联合输出更新均减少漏检并降低场损失。本轮样本中，Set 分类与体素总损失的输出梯度内积均为正；验证组平均余弦约为 0.191、0.193、0.198。余弦衡量整体方向是否一致，正值表示并非整体相反。

因此，可以讨论“分类目标对语义幅度的局部副作用”，但证据不支持“两个目标的整体梯度普遍冲突”。联合参数更新在独立场景中的漏检效应区间包含零，也不能宣称其稳定有害。

## 7. 目前应怎样表述机制与下一步工作？

| 现在可以表述 | 现有证据尚不能支持的结论 |
| --- | --- |
| 在本配置的局部更新中，分类监督能够经幅度变化影响 empty 决策 | 这条路径解释了全部 empty 漏检 |
| 真实最后分类参数能够把该效应传递到独立场景 | 完整 AdamW 训练中该效应始终占主导 |
| 匹配漏检体素的支持更低 | 支持差异已被证明由某种几何训练错误造成 |
| 恢复幅度能够减弱本轮漏检副作用 | 恢复幅度一定比原模型或类别 bias 的 mIoU 更高 |

本轮只涉及一种 OPUS Gaussian 配置、一个训练 seed、同一训练轨迹的三个 checkpoint。GaussianFormer-2 没有新增权重实验。不同模型出现相似 empty 现象，也不自动意味着共享相同训练机制。

下一步方法设计应保留类别 bias 作为强基线，检验能否减少 Set 分类对语义总幅度的副作用，并在实际参数更新与完整训练中复查。各方法需要获得同等类别 bias 学习与选择机会，同时报告 mIoU、漏检、误占用和速度。

Gaussian 未归一化聚合与重叠已有相关讨论，见 [GaussianFormer-2 第 3.1–3.2 节](https://arxiv.org/html/2412.04384v2)。本轮的具体证据是“实际分类更新—幅度变化—empty 决策”的局部作用链；其新颖性仍需结合完整相关工作判断。
