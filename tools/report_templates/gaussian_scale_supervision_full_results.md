# 空区域高斯为何仍产生前景预测：全数据实验结果

**本轮确认了一个局部问题：空体素 CE 已经要求部分错误高斯缩小，但尺度转换中的 sigmoid 饱和使这条梯度无法传回原始尺度输出。直接统一缩小高斯，则会造成大量漏检。**

数据覆盖全部 **700 个训练场景和 150 个验证场景，共 34,149 帧、2,622,643,200 个高斯实例**，没有筛选子数据集。使用冻结的 8 帧 tiny 权重，模型是“加性渲染 + 可学习 empty bias”。全部体素指标默认在 camera mask 内计算；训练集也按确定性推理流程重新评估。

阅读建议：第 1 节定义研究对象，第 2～5 节依次回答监督、损失冲突、尺度梯度、干预效果四个问题，第 6 节说明结论能走到哪一步。补充统计与数值审计放在附录；复现实验见[设计文档](gaussian_scale_supervision_full_design.md)。

## 1. 先确认：我们找到的是哪种错误高斯

本报告重点研究同时满足以下两个条件的高斯，简称**“纯空且主导 FP”组**：

1. 在 camera mask 内，实际受它影响的有效体素全部标为 empty。
2. 至少有一个 empty 体素被模型误预测为前景，而且该高斯对这个预测类别的贡献最大。

FP 即假阳性，也称误占用。“贡献最大”是一种错误归属规则，不能说明一个高斯独自造成了错误；多个高斯可以共同参与同一个 FP。

### 这组高斯很少，但在验证集上关联了较多错误

下表将三个不同分母直接写入指标名称。高斯按每帧实例计数，FP 按体素计数。

{{focus_table}}

验证集中，该组高斯占全部高斯的比例是训练集的 **{{frequency_ratio}} 倍**。它们平均不透明度高、语义值高，尺度也接近上限；完整属性见附录 A。这里的语义值是 softplus 输出，**不能当作前景概率**。

### 会不会只是 mask 外高斯的尾部扫到了空区域？

这种情况确实可能存在，因此我们增加了两项更严格的检查：

- **中心可见且为空：**重点组中，中心所在体素本身也位于 camera mask 内，GT 为 empty。
- **整个影响范围都为空：**重点组中，连同 mask 外的实际影响范围一起检查，也找不到前景 GT。

{{strict_overview}}

两类高斯可以重叠，不能相加。验证集中，仅“中心可见且为空”这一类就归属了全部 FP 的 **{{visible_fp_share}}**。因此，现象确实包含位于可见空区域中的错误高斯。

图中中心位置的三类互斥；“整个影响范围都为空”是另一项可以与它们重叠的检查。

## 2. 空体素 CE 已经向这些高斯施加约束

**这些高斯并非完全没有进入 occupancy CE。** 几乎全部重点组高斯都收到压低目标类别得分的梯度，全部都收到至少一个轴的缩尺度要求。

这里的“目标类别”指 Set loss 按最近前景 GT 分配的类别，未必是 FP 体素最终预测的类别。“可见覆盖比例”按几何核权重计算：camera mask 内的权重和除以整个网格内的权重和。

{{supervision_table}}

表中梯度比例的分母均为“纯空且主导 FP”组的高斯数。“100.000%”保留三位小数；压低目标类的比例在验证集实际略低于 100%。

**这一步排除了“完全没有空体素监督”的解释，但没有证明监督足够强。** 网络会同时处理其他高斯、其他损失和其他样本；当前输出有压低方向的梯度，并不保证此前训练已经把它压低。

## 3. Set 与 CE 在目标类别上常有冲突，但整体幅度的结论不同

需要分开看两个操作：一是只改变 Set 指定的目标类别得分；二是保持各类别比例，让全部前景语义值一起增减。

例如，Set 可以提高“汽车”得分，同时压低其他前景类别。因此，“抬高某一个类别”不能直接写成“抬高整体前景贡献”。

{{conflict_table}}

除“绝对梯度总量比”外，上表各行都是以重点组高斯数为分母的发生率。总量比先分别累加组内空 CE、Set 的梯度绝对值再相除；它既不是发生率，也不是逐高斯比值的平均。

“合计”包括空体素 CE、前景体素 CE、Lovasz、最后阶段 Set 分类，使用原始损失权重。由于这组高斯在监督范围内只影响 empty，前景 CE 和 Lovasz 对其直接梯度为零。

可以确认，目标类别上的方向冲突很常见，且验证集中合计仍希望抬高该类别的比例更大。但对“全部语义值一起增大”这个方向，合计支持它的比例为零。**现有证据不支持“Set 普遍让这些高斯的整体前景幅度增大”。**

这里比较的是最终输出的直接梯度。它不等于共享网络参数的实际更新，也不包含 Set 几何项和其他阶段的完整训练作用。

## 4. 尺度转换使部分缩小要求无法传回

模型先预测原始尺度数值 $t$，再转换成以米计的尺度 $\sigma$：

$$
\sigma=0.08+0.32s,\qquad s=\operatorname{sigmoid}(t).
$$

损失 $L$ 对实际尺度的调整要求，传回原始输出时还要乘一个系数：

$$
\frac{\partial L}{\partial t}
=\frac{\partial L}{\partial\sigma}\,0.32s(1-s).
$$

**当 sigmoid 在实际 FP32 计算中达到 1 时，后面的系数为零。** 即使损失要求缩小实际尺寸，这条数据梯度也传不回原始尺度输出。

{{scale_focus_table}}

第一、二行的分母均为重点组高斯数；第三行是按物理尺度梯度绝对值加权的系数比值，不是高斯数量比例。尺度转换系数的最大值为 0.08。

这个结果使用实际捕获的原始输出计算，未从舍入后的尺度反推。若再限定“中心可见且为空”，验证集中仍有 **{{visible_scale_zero}}** 的高斯出现“CE 要求缩小、但三轴原始尺度梯度全为零”。

![不同高斯组的三轴尺度接近上限情况与零梯度比例](figures/gaussian_scale_supervision_full/saturation.png)

**但“尺度大”本身不能等同于错误。** 验证集纯前景组中，三轴都达到 0.39 米的比例也有 {{foreground_saturated}}；占有损失对这组各轴约有 86% 的高斯仍要求扩大尺度。当前核没有体积归一化，扩大尺度既改变覆盖，也通常增加前景贡献。附录 B 列出不同组的完整比较。

因此，本轮确认的是**一条局部尺度梯度通路受阻**。它尚不能说明整个网络停止更新，也没有证明尺度饱和是最终误占用或泛化差距的主导原因。

## 5. 统一缩小高斯会显著增加漏检

### 5.1 四组对照分别改了什么

只依据尺度选择高斯：最大轴至少为 0.39 米，将超过 0.30 米的轴限制到 0.30 米。选择过程不用 GT 和错误标签，所以也会影响有用的前景高斯。

“贡献总量”指单个高斯在 camera mask 内、全部前景类别上的渲染 logit 贡献之和。中心、旋转和 empty 得分在所有条件下保持固定。

| 条件 | 尺度变化 | 前景贡献总量变化 |
|---|---|---|
| B0：原始模型 | 不变 | 不变 |
| S：直接缩小 | 限制到 0.30 米 | 随尺度一起减少 |
| O：只降低贡献 | 不变 | 降低不透明度，逐高斯匹配 S |
| R：缩小后补回贡献 | 与 S 相同 | 放大语义值，逐高斯恢复到 B0 |

### 5.2 原始决策阈值下：假阳性减少，但漏检大幅增加

先看验证集。漏检率和错分类率都以 GT 前景体素为分母；假阳性率以 GT empty 体素为分母。

{{val_metrics}}

直接缩小后，假阳性率从 **{{base_fp}} 降至 {{shrink_fp}}**，但漏检率从 **{{base_miss}} 升至 {{shrink_miss}}**，mIoU 因而明显下降。错分类率变低也不能单独视为改善：被改判为 empty 的前景体素会计入漏检，不再计入错分类。

训练集也出现相同方向：

![原始阈值下，四组条件的性能与两类占有错误](figures/gaussian_scale_supervision_full/interventions.png)

这四组对照支持以下解释：

- **S 与 O 都大幅增加漏检：**只降低贡献就能造成相似的退化，不能把 S 的全部变化都归因于几何形状。
- **S 优于同总量的 O：**空间分布确实影响结果，但当前 S 仍远低于原模型。
- **R 恢复总量后仍未超过 B0：**当前这种统一缩小、再补回贡献的操作也没有带来收益。

### 5.3 重新调整前景／empty 阈值后：大量退化可以恢复，但没有明确收益

缩小或降低贡献后，继续使用原阈值可能过于偏向 empty。因此，再允许各组调整决策阈值，但要求 FP 总数不超过该集合原模型的 FP 数量。

阈值作用于“最高前景 logit 减去 empty logit”：差值达到阈值才预测前景。负阈值更容易预测前景。下表为验证集：

{{val_matched}}

S、O 的 mIoU 大幅恢复，说明原生性能下降包含明显的整体得分与阈值变化。O 比 B0 高约 **{{matched_gain}} 个百分点**，但它使用当前评价集合的 GT 选择阈值，实际 FP 率也并不完全相同，且没有重选阈值后的置信区间，不能据此宣称可靠方法收益。

![不同决策阈值下的漏检与假阳性关系](figures/gaussian_scale_supervision_full/decision_curves.png)

训练集阈值结果、总量匹配误差和极端放大系数见附录 C。R 是固定输出诊断，其表现不代表可学习归一化渲染的性能上限。

## 6. 这轮实验把机制判断推进到了哪里

| 判断 | 当前证据 |
|---|---|
| 可见空区域中存在高前景贡献、并关联实际 FP 的高斯 | 支持；中心位置和整个影响范围均做了更严格复核 |
| 它们只是因为 camera mask 而没有接受 CE | 不能解释本轮重点组；已测到直接空体素梯度 |
| Set 与空体素 CE 在目标类别上存在竞争 | 支持；但不能推广为整体前景幅度普遍上升 |
| 尺度参数化会阻断部分应当缩小的梯度 | 支持；实际原始输出和 FP32 sigmoid 已复核 |
| 这种阻断是最终 FP 或泛化退化的主导原因 | 尚未证明；缺少训练干预 |
| 统一缩小高斯已经构成有效解决方法 | 当前结果不支持；漏检和 mIoU 明显退化 |

下一项最有辨别力的因果实验，是尽量保留初始前向预测，只改变饱和区域的缩尺度梯度能否传回，再通过真实训练比较完整验证集的 FP、漏检和 mIoU。这样才能进一步判断这条局部通路对最终错误贡献了多少。本轮尚未执行该训练对照。

### C.1 训练集：FP 总数不超过原模型时

{{train_matched}}

所有条件采用同一规则：从 −5 到 5、步长为 0.05 的阈值网格中，选择满足预算的最低阈值。离散网格无法保证 FP 数量完全一致。

### C.2 逐高斯总量匹配是否准确

{{control_quality}}

原始与缩小后的 camera 核权重和均大于 $10^{-30}$ 才执行干预；否则四组均保留原输出。逐帧检查渲染后的前景总量，S/O 与 R/B0 的最大相对误差约为 $10^{-7}$，全部输出均为有限值。

R 的极端恢复倍数可超过一百万。这是诊断对照的重要限制，应与其性能结果一起阅读。
